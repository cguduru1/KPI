# KPI Management System

A full‑stack application for managing employee KPIs, performance reviews, and audit logs.  
Built with **Node.js + Express + MongoDB** on the backend and **React + Vite** on the frontend.

---

## 🚀 Features
- Role‑based access (Employee, Supervisor, DeptHead, HR)
- KPI creation, submission, approval workflow
- Performance review tracking with forced acceptance logic
- Audit logging for all critical actions
- Bulk actions for HR (force close/accept KPIs)
- Export reports to PDF, CSV, and Excel
- Sentiment analysis and regression analytics for KPI data
